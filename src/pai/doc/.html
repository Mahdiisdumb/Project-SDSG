Castiel SDK

Castiel is the simple game scripting SDK for SDSG.

It exists so you can make games without writing browser boilerplate, canvas setup, event listeners, animation loops, or giant piles of JavaScript.

Castiel 3.0
Write the game. Castiel handles the boring shit.

The Basic Idea

A Castiel game normally only needs one file: game.js. 

Castiel.game({
    init() {
        this.player =
            Castiel.rect(
                300,
                200,
                40,
                40,
                '#716fee'
            );
    },

    update(dt) {
        Castiel.clear();

        Castiel.move(
            this.player,
            200,
            dt
        );

        this.player.draw();
    }
});

You do not need to create the canvas. You do not need requestAnimationFrame(). You do not need addEventListener(). You do not need to create your own keyboard system.

Game

Castiel.game(definition)

Creates your game definition. 

Castiel.game({
    init() {
        // Runs once.
    },

    update(dt) {
        // Runs every frame.
    },

    destroy() {
        // Runs when the game stops.
    }
});

dt

dt is the time since the previous frame in seconds. Use it for movement so your game does not depend on FPS. 

player.x += 200 * dt;

Castiel.stop()

Castiel.stop();

Stops the game loop.

Castiel.restart()

Castiel.restart();

Restarts the game by reloading the game page.

Objects

Castiel.rect(x, y, width, height, color)

Creates a rectangle game object. 

player = Castiel.rect(
    100,
    100,
    50,
    50,
    'red'
);

Rectangle objects automatically provide:

  • x
  • y
  • width
  • height
  • color
  • visible
  • destroyed
  • draw()
  • destroy()
  • touching(other)
  • moveTowards(target, speed, dt)
  • bounds()

Castiel.circle(x, y, radius, color)

Creates a circle game object. 

ball = Castiel.circle(
    300,
    200,
    25,
    'blue'
);

Circle objects provide:

  • x
  • y
  • radius
  • color
  • visible
  • destroyed
  • draw()
  • destroy()
  • touching(other)

object.draw()

player.draw();

Draws the object if it is visible and has not been destroyed.

object.destroy()

enemy.destroy();

Marks the object as destroyed. Destroyed objects are removed from Castiel's internal object list.

object.touching(other)

if (player.touching(enemy)) {
    Castiel.restart();
}

Checks whether two supported objects are touching.

object.bounds()

const bounds = player.bounds();

console.log(bounds.x);
console.log(bounds.y);
console.log(bounds.width);
console.log(bounds.height);

Returns the object's rectangular bounds.

Groups

Use groups instead of manually maintaining arrays of game objects. 

enemies = Castiel.group();

enemies.add(
    Castiel.rect(
        100,
        50,
        40,
        40,
        'green'
    )
);

enemies.each(enemy => {
    enemy.moveTowards(
        player,
        100,
        dt
    );
});

group.add(object)

Adds an object to the group.

group.remove(object)

Removes an object from the group.

group.clear()

Destroys everything in the group and empties it.

group.each(callback)

Runs the callback for every living object. 

enemies.each(enemy => {
    enemy.draw();
});

group.length

console.log(enemies.length);

Returns the number of objects currently stored in the group.

group.all

const objects = enemies.all;

Returns the group's internal object array.

Movement

Castiel.move(object, speed, dt)

Uses WASD and arrow keys to move an object. 

Castiel.move(
    player,
    200,
    dt
);

This replaces manually checking four keyboard keys.

Castiel.moveTowards(object, target, speed, dt)

Castiel.moveTowards(
    enemy,
    player,
    100,
    dt
);

Objects also expose this directly: 

enemy.moveTowards(
    player,
    100,
    dt
);

Timing

Castiel.every(seconds, callback)

Runs a callback repeatedly at the specified interval. 

Castiel.every(1, () => {
    spawnEnemy();
});

The returned timer can be stopped. 

const timer =
    Castiel.every(1, () => {
        spawnEnemy();
    });

timer.stop();

Castiel.after(seconds, callback)

Runs a callback after a delay. 

Castiel.after(2, () => {
    Castiel.log('Two seconds passed.');
});

Collision

Castiel.rectCollide(a, b)

if (Castiel.rectCollide(
    player,
    enemy
)) {
    enemy.destroy();
}

Performs rectangle-to-rectangle collision detection.

object.touching(other)

For normal objects, this is usually simpler: 

if (player.touching(enemy)) {
    enemy.destroy();
}

Castiel.pointInRect(x, y, rect)

const mouse = Castiel.mouse();

if (
    Castiel.pointInRect(
        mouse.x,
        mouse.y,
        button
    )
) {
    Castiel.log('Clicked button');
}

Random Numbers

Castiel.random(min, max)

Returns a random decimal number between the specified values. 

const x =
    Castiel.random(
        0,
        Castiel.width()
    );

Castiel.randomInt(min, max)

Returns a random integer between the specified values, including both endpoints. 

const enemyCount =
    Castiel.randomInt(3, 10);

Images

Castiel.image(src)

Creates an image immediately. 

const playerImage =
    Castiel.image(
        'player.png'
    );

Castiel.loadImage(src)

Loads an image asynchronously and resolves when it is ready. 

let playerImage;

async init() {
    playerImage =
        await Castiel.loadImage(
            'player.png'
        );
}

Castiel.drawImage(image, x, y)

Castiel.drawImage(
    playerImage,
    100,
    100
);

Castiel.drawImage(image, x, y, width, height)

Castiel.drawImage(
    playerImage,
    100,
    100,
    64,
    64
);

Audio

Castiel.sound(src)

Creates a sound object. 

shootSound =
    Castiel.sound(
        'shoot.wav'
    );

sound.play(volume)

Plays the sound from the beginning. Volume ranges from 0 to 1. 

shootSound.play();

shootSound.play(0.5);

sound.stop()

shootSound.stop();

Stops the sound and resets it to the beginning.

sound.pause()

shootSound.pause();

Pauses the sound without resetting its position.

Files

Castiel can communicate with the desktop host for simple file operations when the game is running inside the Castiel editor.

Important: Host file access depends on the Castiel desktop host. A normal browser cannot provide these operations.

Castiel.write(path, content)

Castiel.write(
    'save.txt',
    'score=100'
);

Writes text through the Castiel desktop host.

Castiel.read(path)

const save =
    Castiel.read(
        'save.txt'
    );

Reads text through the Castiel desktop host.

Logging

Castiel.log(message)

Castiel.log(
    'Enemy spawned'
);

Writes a normal Castiel message to the browser console and sends it to the desktop host when available.

Castiel.error(message)

Castiel.error(
    'Could not load level'
);

Writes an error message to the console and reports it to the desktop host when available.

Complete Example

This is intentionally small. You should not need hundreds of lines for a simple SDSG game. 

Castiel.game({
    init() {
        this.player =
            Castiel.rect(
                300,
                400,
                40,
                40,
                'red'
            );

        this.enemies =
            Castiel.group();

        Castiel.every(1, () => {
            this.enemies.add(
                Castiel.rect(
                    Castiel.random(
                        0,
                        Castiel.width() - 40
                    ),
                    0,
                    40,
                    40,
                    'green'
                )
            );
        });
    },

    update(dt) {
        Castiel.clear();

        Castiel.move(
            this.player,
            250,
            dt
        );

        this.player.draw();

        this.enemies.each(enemy => {
            enemy.moveTowards(
                this.player,
                100,
                dt
            );

            enemy.draw();

            if (
                enemy.touching(
                    this.player
                )
            ) {
                Castiel.restart();
            }
        });
    }
});
